## 機能突合（MVP × 扱い）

| 本番 MVP | 扱い | メモ |
|---|---|---|
| POS設定（税率・端数・表示） | 含める | |
| 商品マスター（大/中/小・taxType） | 含める | シードのみ。スプシ取込は対象外 |
| フロア俯瞰・空席/接客 | 含める | |
| テーブル接客（人数・メモ・注文） | 含める | |
| テイクアウト起票・会計分離 | 含める | |
| 注文（追加・取消・数量・提供状態） | 含める | |
| 提供コンソール | 含める | |
| 会計（現金/カード/電子・おつり・未提供確認） | 含める | 実決済端末なし |
| バッジ（提供前・滞在） | 含める | |
| 売上・本日集計・日締め | 含める | |
| 認証（Firebase Auth + storeId claim） | 含める | 固定 `demo`。サインアップなし |
| 赤伝 UI | 含める | ロール制限なし（本番同様） |
| バックヤード（メニュー・フロア・タグ・設定） | 含める | 乱用面はリセットで抑える |
| レシート／プリンタ HW | 対象外 | §4.3 既定 |
| LINE テイクアウトチャネル | 対象外 | §4.3 既定 |
| 在庫・予約・会員・細権限・オフライン完全 | 対象外 | 本番 MVP 外 |
| スプシ双方向同期 | 対象外 | |
| 本番データ・顧客ブランド | 除外 | 絶対除外 |
