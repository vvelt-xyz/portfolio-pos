WELT POS — Operate

株式会社WELT 公開デモ · 本番店舗ではありません

  1. ログイン画面で「デモアカウントで入る」、または ID demo と README のパスワード。
  2. ホーム →「フロアを開く」。空席を選び人数を入れて起票する。
  3. 注文画面でメニューを追加する。数量変更・取消も試せる。
  4. 「提供コンソール」で未提供を提供済にする（別端末想定）。
  5. フロアから会計へ。支払方法を選び確定。ホームの「本日の集計」を見る。

データは共有シードです。他の評価者と同時に触ると操作が見えます。壊れたら管理者のリセット手段を使います。
